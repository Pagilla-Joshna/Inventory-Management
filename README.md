# Inventory Management System

A Flask-based web application designed to simplify inventory tracking,
stock management, product categorization, user management, and
inventory analysis.

## Overview

The Inventory Management System provides a centralized web interface
for monitoring and managing inventory.

The application allows users to view products, quantities, categories,
remaining stock, used stock, low-stock items, expired products, and
inventory usage trends.

The system uses Flask for the backend and HTML, CSS, and JavaScript for
the frontend. Inventory data is managed using Excel and CSV files.

## Features
User login and authentication
Product and inventory management
Category-wise product organization
Stock quantity tracking
Low-stock and out-of-stock alerts
Expiry date tracking
Usage trend analysis
User and role management
Interactive dashboard

How to Run
Clone the repository:
```text
git clone https://github.com/Pagilla-Joshna/Inventory-Management.git
cd Inventory-Management
```
Install dependencies:
```text
pip install -r requirements.txt
```
Run the application:
```text
python app.py
```
Open the application in your browser at:

http://127.0.0.1:5000
